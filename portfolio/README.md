# portfolio

The Next.js site — the deployable that goes to Vercel. Content comes from the Sanity
Studio in [`../portfolio-studio`](../portfolio-studio), with hardcoded fallbacks in
`src/content/fallbacks.ts` for when the CMS is empty or unreachable.

See the [root README](../README.md) for what the project is and the stack, and
[`../PRD.md`](../PRD.md) for the full technical reference.

## Run it

```bash
npm install
cp .env.example .env.local   # optional — the site renders from fallbacks without it
npm run dev                  # http://localhost:3000
```

## Scripts

| Command                                    | What it does                                            |
| ------------------------------------------ | ------------------------------------------------------- |
| `npm run dev`                              | Dev server                                              |
| `npm run build`                            | Production build                                        |
| `npm run start`                            | Serve the production build                              |
| `npm run lint`                             | ESLint                                                  |
| `npm run format` / `format:check`          | Prettier write / check                                  |
| `node scripts/reset-stats.mjs`             | Show every counter, change nothing                      |
| `node scripts/reset-stats.mjs <env> --yes` | Reset `development`, `preview` or `production` counters |

## Layout

```
src/app/          routes, layout, API handlers, globals.css
src/components/   sections/ · projects/ · ui/
src/hooks/        useFocusTrap
src/lib/          cms, content, format, animations, redis, rateLimit, resend, contact, visit
src/sanity/       client, queries, fetch, devicon
src/content/      fallback content
src/types/        CMS-shaped types
```

## Notes

- Fonts are Space Grotesk (headings) and Inter (body) via `next/font`.
- Tailwind v4 is configured CSS-first in `src/app/globals.css` — there is no `tailwind.config.js`.
- `src/lib/cms.ts` is server-only (it pulls in `@sanity/client`); client components use the
  sync accessors in `src/lib/content.ts` instead, so the Sanity client stays out of the browser bundle.
- `AGENTS.md` is regenerated by `next dev` and is excluded from Prettier.
